# اصلاحات پیشنهادی برای ریپو docker-compose

## بحرانی (CRITICAL) — فوری اصلاح شود

### 1. حذف رمزهای عبور hardcoded از فایل‌ها
ده‌ها فایل docker-compose دارای رمز عبور hardcoded هستند که نباید در ریپو باشند:

| فایل | رمز |
|------|-----|
| `Infrastructure/keycloak/docker-compose.yml` | `KEYCLOAK_ADMIN_PASSWORD=admin` |
| `Infrastructure/development/jira/docker-compose.yml` | `MYSQL_ROOT_PASSWORD=123456` |
| `Infrastructure/jenkins/docker-compose.yml` | `user: root` + `privileged: true` |
| `Infrastructure/Monitoring/docker-compose.yml` | `rootpass`, `zabbix_pass`, `admin` |
| `Infrastructure/kibana/kibana.yml` | `elasticsearch.password: "test"` |
| `recently/hopscotch/.env.example` | GitHub OAuth secret واقعی |
| `recently/posthog/docker-compose.yml` | `SECRET_KEY=32ce44bf...` |
| `recently/openproject/compose/docker-compose.yml` | `p4ssw0rd` |
| `server/tubearchivist/docker-compose.yml` | `TA_PASSWORD=verysecret` |
| `server/paperless-ngx/docker-compose.yml` | `POSTGRES_PASSWORD=paperless` |

**اقدام:** جایگزینی با متغیرهای env و ایجاد `.env.example` فایل‌ها

### 2. اصلاح .gitignore
فایل `.gitignore` فعلی ناقص است. اضافه شود:
```
*.key
*.pem
*.p12
*-secret.yaml
.env.prod*
.env.dev*
docker-compose.override.yml
```

### 3. حذف کلید خصوصی SSL متعهد شده
- `Stacks/PHP/yii2-docker/php/image-files/nginx/etc/nginx/ssl/nginx-selfsigned.key` — کلید RSA 2048-bit در ریپو

### 4. اصلاح healthcheck شکسته
- `recently/hopscotch/healthcheck.sh` — تابع `heck()` تعریف شده ولی `curlCheck` صدا زده می‌شود. همچنین shebang ندارد.

### 5. حذف atlassian-agent.jar (نرم‌افزار crack)
- `Infrastructure/development/jira/Dockerfile` — دانلود و استفاده از atlassian-agent.jar
